# 女主演目录

配置项“按女主演分目录”默认关闭。开启后，自动与手动整理都在用户所选媒体库目录下创建“女主演姓名 / 原生影片目录 / 视频”的布局；插件继续调用 MoviePilot 原生预览与整理入口，保留源下载。

插件只接受 ATTACKERS 官方页面唯一、结构完整的“女優”行作为自动依据，并要求其中唯一姓名与本片已识别演员精确对应。官方列出多人时，即使当前演员表只匹配其中一人，也必须由用户选择。没有可靠证据、多位或不匹配时必须由用户从当前影片演员中选择一人。演员顺序、性别字段、头像和名字均不能作为推断依据。若官方结果明确列出女優，手动选择范围限制在其与本片演员的交集；否则只能从本片非空演员名单中由用户明确选择。

手动预览遇到待选择项时返回演员候选与选择状态，并且在选择完成、重新预览前不调用原生 transfer。执行必须基于新预览，并重新核验来源文件、媒体来源与 ID、选择项、选择依据、配置签名、目录范围和目标。自动选出的唯一官方姓名在执行时若变得有歧义，必须拒绝提交；人工选择则须仍属于当前有效候选。姓名必须是安全的单个目录组件；预览不创建目录，目标路径仍由原生预览返回。现存演员子目录若为符号链接或非目录必须拒绝；预览后被替换时执行也必须拒绝。

自动整理若无法唯一确定女主演，应以明确原因 `primary_actress_choice_required` 停止，留下待人工选择提示并可通过现有手动页处理；不得反复领取或标记完成。不得修改 MoviePilot 核心、metadata-v2 缓存路径或账本 schema。

旧配置默认关闭，公开 MediaInfo 结构不变。开关进入手动配置与自动 handoff 签名；开启时旧缓存不能作为缺少官方证据的确认依据。版本为 0.8.4。
