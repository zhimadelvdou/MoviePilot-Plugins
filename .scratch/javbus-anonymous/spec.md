# JavBus 匿名来源接入规格

目标：让 JavBus 作为可选元数据来源接入现有 offline adapter 与单一 `sources` 设置。仅实现匿名 HTTP 路径，不添加账户、Cookie、浏览器服务或新依赖；FANZA 本轮搁置。

## 行为合同

- `sources` 缺省继续只有 Manko；已有显式值（包括仅 Manko、空列表及其他自选值）保持不变。只有用户保存包含 JavBus 的多选后，来源才同时可用于手动菜单与自动识别。
- JavBus 搜索和回查均要求解析到精确相同的番号/ID。核心字段为 ID、番号、标题、演员、日期；导演与片商允许缺失。兼容 `avatar-box` 与 `star-name` 演员结构，不推断演员性别或可信女优标记。
- 对验证页/driver-verify、429、真正登录页、404、网络/超时分别给出安全且准确的来源诊断；不记录正文、完整 URL、query、Cookie、代理或异常文本。
- 只有 Manko 的明确演员证据可支持默认女优与女优分目录。非 Manko 来源需要人工选择；自动流程缺少证据时明确等待。
- 不变更 MoviePilot 前后端、生产部署、运行配置或 FANZA 行为。

## 验收

- 隔离 SDK 合成回放覆盖当前 JavBus 标记与 `star-name` 结构、核心字段、可选导演/片商、错误身份和受限响应诊断；同步/异步结果一致。
- 来源缺省/显式列表保留、手动来源选择和预览身份通过既有 SDK 接口验证。
- JavBus 实站仍未验收：ROOT 在 2026-10-25 的只读请求收到 driver-verify 重定向或 HTTP 429；不得将其标为成功、not_found 或必需登录。
